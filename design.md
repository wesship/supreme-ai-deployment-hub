# D3VONN.IO Visual Operating System

This file is the public design authority for D3VONN.IO. It keeps the homepage from drifting into a generic AI startup pattern.

## Purpose

D3VONN.IO should feel like a sovereign AI command system: cinematic, technical, secure, intelligent, and premium.

## Required brand architecture

The public page should clearly reference:

- D3VONN.IO
- DEVONN.AI
- Hermes
- DKOS
- RAG
- agent workforce
- signal intelligence
- security

## Visual rules

Use asymmetric command-panel layouts, signal rails, orbital motion, technical labels, metallic blue surfaces, restrained gold accents, and mission-control spacing.

Avoid generic centered SaaS sections, filler marketing language, excessive glassmorphism, generic blue-purple gradients, and repeated icon-card grids.

## Level 3 Design Testing

Design changes should be testable. Static checks should guard against banned filler words and missing architecture terms. Visual checks should confirm the homepage renders on desktop and mobile and keeps the command-center treatment visible.

## Self-Refinement Rule

After major public design changes, update this file with what looked generic, what worked, and which rules should be encoded as tests next.
