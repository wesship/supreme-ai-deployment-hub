# D3VONN.IO Visual Operating System

D3VONN.IO should feel like a sovereign AI command system, not a generic AI startup page.

## Brand Feeling

D3VONN.IO represents DEVONN.AI agent orchestration, Hermes routing, DKOS knowledge, RAG memory, signal security, workflow automation, and agent workforce execution.

## Visual Rules

- Use metallic blue, silver, deep navy, and restrained gold.
- Keep the homepage command-focused.
- Avoid generic centered AI SaaS layouts.
- Avoid generic filler language.
- Keep D3VONN.IO, Hermes, DKOS, RAG, agent, signal, and security terms visible.

## Level 3 Design Testing

Static tests should check required architecture terms, banned generic words, and common AI-site anti-patterns.

## Self-Refinement Rule

After each major design pass, record what worked, what looked generic, and what should be avoided next.
