# Apple Vision Pro — Safari window mode

Open `/holo?display=vision-pro` directly in Safari on Vision Pro. The display picker also offers this mode. Use the native look-and-pinch click to select a card, then Open; all cards are available in an always-visible selector. Controls have at least 44px targets. Enlarge or reposition the Safari window using visionOS. Webcam controls are hidden and switching display modes stops any existing tracking stream.

This mode adds browser click compatibility. It does not access continuous eye tracking, headset cameras, hand skeletons, native ARKit or immersive WebXR. Physical Vision Pro acceptance remains open; ordinary browser interaction tests cannot certify the headset.

For host webcam gestures while using Mac Virtual Display, select Monitor mode in the Mac browser and use a camera connected to the Mac that can see your hands. Do not interpret the host camera as a connection to Vision Pro sensors.

The header's Download prompt pack provides original D3VONN starter/device-help prompts at `/holo/D3VONN_PROMPT_PACK.md`. The pack does not include third-party paid/private prompts. It does not automatically run commands or include private note contents in voice context.

Official references: https://support.apple.com/117741 and https://webkit.org/blog/15162/introducing-natural-input-for-webxr-in-apple-vision-pro/
