# PRIMETIME / Primerica App Prompt Codes

These are custom shorthand instructions for the PRIMETIME Project, Devonn.AI, the Primerica CRM, insurance training tools, and AI-agent workflows. They are not hidden ChatGPT commands.

## Usage

```text
[PROJECT] + [FUNCTION] + [QUALITY CHECK] + [OUTPUT FORMAT]:
[Instruction]
```

Example:

```text
PRIMETIME + CRM-AUDIT + COMPLIANCE-CHECK + TABLE:
Review the contact, lead, task, and appointment systems.
```

## Interpretation rules

1. Codes may be combined with `+`.
2. The text after `:` is the task body.
3. Master codes expand before task execution.
4. Compliance, privacy, consent, licensing, and human-approval codes override speed or automation preferences.
5. `HUMAN-APPROVAL` and `ESCALATE-LICENSED` create mandatory approval gates.
6. Output-format codes control presentation but do not override safety or factual verification.
7. When a code requires current law, platform behavior, pricing, licensing, or product information, the system must verify current authoritative sources.
