# MakeBIGFILMS VFX integration

Status: implemented as a governed **catalog-routing provider** for D3VONN.IO AI Films.

## Why this is not a video-generation adapter

MakeBIGFILMS is treated as a source of licensed production VFX assets. The public product exposes curated collections and a project workspace, but D3VONN does not assume a documented machine-download API exists. The integration therefore performs scene classification and collection routing without scraping, bypassing access controls, or automatically downloading licensed media.

Provider contract:

- capability: `vfx_asset`
- provider: `makebigfilms`
- integration mode: `catalog_routing`
- execution mode: `operator_authorized_asset_import`
- optional configuration: `MAKEBIGFILMS_PROJECT_URL`
- source of record after import: D3VONN.IO AI Films artifact pipeline

## Runtime flow

```text
Screenplay / Shot Manifest
        |
        v
Hermes / AI Director scene analysis
        |
        v
POST /api/ai-films/vfx/makebigfilms/resolve
        |
        +--> effect taxonomy
        +--> camera-direction normalization
        +--> ranked MakeBIGFILMS collections
        |
        v
Operator-authorized licensed asset selection/import
        |
        v
AI Films artifact_store
        |
        +--> OpenEXR / compositing
        +--> assembly / mastering
```

## API

### Catalog

`GET /api/ai-films/vfx/makebigfilms/catalog`

Returns the 32 public collection routes plus integration guardrails. No credentials or licensed media are returned.

### Scene resolver

`POST /api/ai-films/vfx/makebigfilms/resolve`

Example request:

```json
{
  "scene_description": "Legend watches a dimensional portal fracture the sky while lightning and debris fall around a giant spaceship.",
  "requested_effects": ["portal", "lightning", "debris", "spaceship"],
  "camera_direction": "front right",
  "limit": 8
}
```

The response ranks candidate collections and returns a governed handoff indicating that a licensed asset must be imported before compositing.

## Governance rules

1. D3VONN must not label a MakeBIGFILMS asset as generated by D3VONN.
2. Automatic asset download is disabled until a documented provider API and licensing-safe adapter are available.
3. Imported assets must preserve provider/license provenance in the artifact record.
4. The D3VONN production/shot manifest remains the system of record; MakeBIGFILMS Projects may be used as an external working collection only.
5. Provider health reports `vfx_asset/makebigfilms` as configured because catalog routing requires no secret; this does **not** mean licensed downloads are automated.
