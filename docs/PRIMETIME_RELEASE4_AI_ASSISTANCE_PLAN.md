# PRIMETIME Release 4 — AI Assistance Plan

## Overview

Draft-first AI assistance layer. The AI does not execute actions autonomously.
All regulated actions (quote, send, delete, autonomous execution) are blocked.

## Non-Negotiable Rules

- AI does not execute autonomous regulated actions
- No quote generation without human review
- No delete of any regulated record
- No send of any communication autonomously
- All AI outputs are draft-first

## Governance Boundaries

The following are explicitly forbidden:
- Autonomous execution of regulated actions
- Quote generation endpoint
- Policy decision endpoint
- Application submission endpoint
- Send message endpoint
- Delete record endpoint
