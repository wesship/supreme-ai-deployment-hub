## Accessibility companions
Every instructional video requires:
- WebVTT captions
- Complete transcript
- Descriptive poster image
- Playback controls
- Reduced-motion behavior
- No automatic audio

## Evidence register
Before publishing a measurable claim, record:
- Claim text
- Source system
- Measurement date
- Environment
- Query or test method
- Reviewer
- Expiration/revalidation date

Claims without an evidence record must be written as design intent, simulation, beta behavior, or planned capability.
