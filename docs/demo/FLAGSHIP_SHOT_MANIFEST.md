# D3VONN.IO Flagship Shot Manifest

## Recording target
- Resolution: 1920 × 1080
- Frame rate: 30 or 60 fps
- Browser zoom: 100%
- Environment: production UI with fictional Acme Manufacturing data only
- Required label: `Product Simulation`

## Admin recording control
Authorized administrators may use `/admin/demo-control` to follow cues and reset the scenario. Do not expose this URL in public marketing materials.

## Capture safety gate
Before each take:
- Disable notifications.
- Hide bookmarks and extensions.
- Confirm no credentials, user emails, tenant IDs, private logs, or internal URLs are visible.
- Confirm all simulation labels are visible.
- Confirm the page is reset before the first state capture.
- Record approval both before and after state transitions.
