# Music provider status

All registered music providers are intentionally disabled on this branch.

The registry adds ACE-Step 1.5 as the default candidate, ACE-Step 1.5 XL Turbo as the premium candidate, and HeartMuLa OSS 3B as the secondary lyrics/style candidate.

Activation remains blocked until immutable source/model revisions, production weight hashes, deployment smoke tests, audio QA, and reviewer approval are complete.
