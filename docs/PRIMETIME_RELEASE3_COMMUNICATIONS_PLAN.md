# PRIMETIME Release 3 — Communications Plan

## Overview

Release 3 introduces consent-governed communications. The system does not send messages autonomously.
All outbound communications require explicit consent verification before dispatch.

## Non-Negotiable Rules

- The system does not send messages autonomously
- Every communication requires a consent check
- No communication without verified consent state
- Autonomous outbound delivery is explicitly blocked

## Governance Boundaries

- No autonomous sending of any message type
- No bypassing consent verification
- No DELETE of consent records
