# D3VONN.IO Global Enterprise Shell

This rollout unifies the public navigation, mobile navigation, footer, EXU brand language, trust entry points, and launch calls to action across D3VONN.IO.

## Included

- Blue-chrome global navigation shell
- EXU Intelligence Gateway identity
- Command Nexus and Trust Center shortcuts
- Responsive mobile navigation with protected-route handling
- Unified enterprise footer and conversion CTA
- Canonical D3VONN.IO logo usage
- Mobile safe-area support and accessible touch targets

## Validation

- `pnpm typecheck`
- `pnpm lint`
- `pnpm test`
- `pnpm build`
- Mobile menu keyboard and screen-reader review
- Responsive visual review from 320px through ultrawide
- Reduced-motion review
