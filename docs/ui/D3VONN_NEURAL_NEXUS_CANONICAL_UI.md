Status: **Approved visual authority**

The production frontend must match the approved D3VONN Neural Nexus reference supplied by the product owner.

- Full-width black/graphite command-center shell.
- Top navigation with D3VONN branding, product navigation, search, alerts, and user controls.
- Left operational rail:
  - Command Center
  - Knowledge Graph
  - Hermes Orchestration
  - Agents
  - Tools & Integrations
  - Workflows
  - Knowledge & RAG
  - AI Films
  - HNF Ecosystem
  - Infrastructure

  - Security

  - D3VONN.IO Institute
- Main center stage:
  - Heading: **Connect Everything. Make It Work.**
  - Graph / Map / List switcher.
  - Search and node filters.
  - Spherical Knowledge Universe composition.
  - Hermes AI Orchestration at the visual center.
  - Major surrounding clusters: People, Knowledge & RAG, Models, AI Films, Agents, Tools & MCP, HNF Ecosystem, Workflows, Infrastructure, Operations, Security.
  - Bottom action bar: Explore, Trace, Run, Connect, Monitor, AI Assist.
- Right rail:
  - System Status
  - Recent Activity
  - Bridge Opportunities
- Bottom command strip:
  - Execution Flow
  - Top Agents
  - Infrastructure
  - Cost & Usage

## Visual system

- Base: black, charcoal, dark metal.
- Primary signal: amber / gold / warm white.
- Supporting semantic colors may be used sparingly for category identity and status.
- No generic blue/purple SaaS gradient treatment as the dominant visual language.
- Thin topology lines, metallic surfaces, glass/etched panels, spatial depth.
- Hermes remains the visual and operational center.
- Motion must indicate actual system state wherever possible.

## Interaction rules

- Graph, Map, and List are alternate views over the same state.
- Selection survives view switching.
- Voice and clicks use the same governed action contract.
- Run routes through Hermes execution.
- Connect requires governance/approval.
- Live Hermes events drive graph propagation and business panels.
- No dead controls.
- No fabricated production metrics.
- Backend identity must resolve to `wesship/supreme-ai-deployment-hub`.
