# D3VONN Product Videos

Drop finished assets here, then register them in `src/config/videos.ts`
(set `mp4`, optional `webm`, `poster`, and `captions`).

Naming convention:
- master-demo.mp4 / master-demo.webm / master-demo.vtt / master-demo-poster.webp
- loop-command-center.webm / .mp4
- loop-knowledge-graph.webm / .mp4
- loop-workflow-builder.webm / .mp4
- loop-movie-studio.webm / .mp4
- loop-security-center.webm / .mp4
- loop-marketplace.webm / .mp4

Standard (see video audit): 16:9, WebM+MP4 for loops, muted autoplay for
loops only, controls + captions + transcript for instructional videos,
maturity label set honestly (Concept / Simulation / Beta / Live Product).
Sections render nothing until a source is configured — no placeholders.
